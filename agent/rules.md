# AI Agent Rules

## Code Style

1. Все SQL-операторы должны быть написаны строчными буквами.
2. Каждый SQL-оператор должен быть написан с новой строки.
3. Каждый SQL-запрос должен заканчиваться символом `;`.
4. Не нужно использовать алиасы, если название колонки при этом не изменится.
5. Любые алиасы должны задаваться с использованием оператора `as`.
6. Если выводятся все колонки из таблицы, то нужно использовать оператор `*`;
6. Каждое задание должно быть отделено от других комментарием в формате:
```sql
-- task <номер задания>
```

Пример корректного оформления:
```sql
-- task 1
select u.id as user_id, u.name
from users as u
where u.is_active = true
order by u.id;
```

## Формат выполнения заданий

1. Структура (DDL) БД содержится в файле [../local-deployment/init_tables.sql](../local-deployment/init_tables.sql).
2. Не нужно выполнять SQL-запросы на реальной базе данных.
3. Не нужно писать комментарии с пояснениями.
4. Можно использовать любые SQL-операторы, если явно не указаны ограничения.
